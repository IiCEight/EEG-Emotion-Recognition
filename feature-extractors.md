# Feature Extractors in This Codebase

All extractors map raw EEG DE features → a 64-d embedding (except where noted). Input data is always **62 electrodes × 5 frequency bands** per sample.

---

## MLP (prpl.py — `FeatureExtractor`)

The simplest extractor. Flattens the input to `[B, 310]` and passes it through two FC layers.

```
310 → FC → ReLU → 64 → FC → ReLU → [B, 64]
```

No graph structure. Used as the `use_gcn=False` baseline in PRPL and OPTA. Fast; no inductive bias about electrode topology. Surprisingly competitive because it avoids the geometric constraints that GCN manifolds impose.

---

## Saber GCN (saber.py — `FeatureExtractor`)

The main extractor for the Saber model. Input shape `[B, 62, 5]`, rearranged internally to `[B, 5, 62]` (band-first).

**Architecture:**
- BatchNorm on the 5 frequency bands
- `MulipleResidualGCN` (2 residual GCN layers over the electrode graph)
- Flatten → FC(→64) → ReLU → FC(64→64) → ReLU

**Graph construction:**  
Global adjacency is a learnable parameter initialized from `get_adj_from_standard()` (physical electrode distances). On top of that, a **per-sample adaptive adjacency** is computed via `SampleAdaptiveAdj`: two 1×1 convolutions project each sample's features to a low-dim space, and their outer product `Q·Kᵀ / √d` modulates the global adjacency. The final adjacency is `A_global + α·A_sample`.

**Key design:**  
Each `ResidualGCN` layer uses grouped Conv2d (one group per frequency band) for the message-passing operation, applies degree normalization, and adds a residual skip. Outputs from all layers are concatenated before flattening.

The per-sample adaptive adjacency is the core innovation: the graph topology varies per sample based on that sample's own frequency-band correlations, introducing controlled stochasticity that helps under best-epoch evaluation.

## PCL Saber Encoder (PCL_SABER.py — `_SaberEncoder`)

A thin wrapper around the Saber `FeatureExtractor` for use in the PCL training pipeline.

```python
def forward(self, x):   # x: [B, 5, 62]
    return self.fe(x), []
```

Returns a tuple `(features [B, 64], [])` — the empty list is a placeholder for auxiliary outputs that other PCL encoders return. Functionally identical to the Saber GCN extractor.

---

## PCL TDGCN Encoder (PCL_TDGCN.py — `Encoder`)

A more complex encoder from the PCL paper's TDGCN variant. Input `[B, 310]`, reshaped internally to `[B, 5, 62, 1]`.

**Architecture:**
- `MHGCN` (Multi-scale Hierarchical GCN, 2 layers)
  - Each layer: `DGCN` with a dynamically generated adjacency
  - Dynamic adjacency: `Graph_Generator` combines memory-based similarity and feature-based similarity, fuses them via a learned FC, then sparsifies (top-80% zeroed out)
- `CBAMBlock` (channel + spatial attention)
- Flatten → FC(→64) → ReLU → FC(64→64) → ReLU

Returns `(features [B, 64], [adj, channel_attn, spatial_attn])`.

**Key design:**  
Adjacency is fully dynamic — generated fresh every forward pass from the current sample's features and a learned memory bank, then sparsified. Unlike Saber's per-sample *modulation* of a global adjacency, here the entire adjacency is generated from scratch. The CBAM block adds both channel recalibration (SE-style) and spatial attention as a post-processing step.

## Dual GCN (saber_RGNN.py — `feature_extractor`)

Input `[B, 310]`, reshaped to `[B, 5, 62, 1]` internally.

**Architecture:**
- Two parallel `MulipleResidualGCN` branches (MRGCN_a, MRGCN_b), each with its own learnable adjacency
- Average the two feature outputs and two adjacency outputs
- `CBAMBlock` on the averaged features
- Flatten → FC(→64) → ReLU → FC(64→64) → ReLU

**Key design:**  
Two independent GCN branches learn different graph topologies; their outputs are averaged. The intuition is that different graphs may capture complementary patterns (e.g., one emotional, one anatomical). CBAM then attends over both channel and spatial dimensions after fusion.

## NSAL-DGAT Encoder (NSAL_DGAT.py — `Encoder`)

Input `[B, 310]`, reshaped to `[B, 5, 62, 1]`.

**Architecture:**
- `MHGCN` with `GATENet`-generated adjacency
  - `GATENet`: FC layers that take a flattened adjacency matrix and transform it; output is reshaped to `[62, 62]` and Laplacian-normalized
- `CBAMBlock`
- Flatten → FC(→64) → ReLU + Dropout → FC(64→64) → ReLU + Dropout

Returns `(features [B, 64], [adj, channel_attn, spatial_attn])`.

**Key design:**  
The adjacency is generated by a small MLP (`GATENet`) that transforms an existing adjacency matrix, rather than constructing it from features. Laplacian normalization (column-normalized, not symmetric) is used instead of symmetric `D⁻¹/²AD⁻¹/²`. Includes dropout in the projection head.

---

## NSAL-DGAT Modified Encoder (NSAL_DGAT_modified.py — `Encoder`)

Same architecture as NSAL-DGAT but with two differences:

1. **Two MHGCN branches** (GGCN_a, GGCN_b), each with their own learnable adjacency, averaged together — same dual-branch idea as `saber_RGNN.feature_extractor`
2. **No GATENet** — adjacency is passed directly as a learnable parameter, not generated by an MLP

Returns `(features [B, 64], [adj, channel_attn, spatial_attn])`.

## RGNN (RGNN.py — `RGNN`)

One of the few extractors that outputs class logits directly rather than a 64-d embedding — it is a full classifier, not just a feature extractor.

Input `[B, 62, 5]`.

**Architecture:**
- `SimpleGraphConv` (K=2 propagation steps, symmetric normalization)
  - Linear: 5 → 128
- Global add pool (sum over 62 electrodes) → `[B, 128]`
- Dropout(0.7) → FC(128→3)

**Graph:**  
Learnable lower-triangular edge weight matrix; symmetrized by copying to upper triangle. If `prior_known_init=True`, initialized from physical inverse-squared distances. Edges are signed — the loss includes a **differential asymmetry penalty** between pairs of brain regions (left-right hemisphere pairs), enforcing neurologically meaningful asymmetry in the learned graph.

Output dim is `num_classes` (3 or 4), not 64.

---

## Temporal GCN (saber_t.py — `TemporalGCNExtractor`)

Designed for multi-window inputs. Input `[B, T, 62, 5]` (T consecutive 1-second windows).

**Architecture:**
- Per-electrode GRU: `[B*62, T, 5]` → hidden state `[B, 62, 16]`
- Reshape to `[B, 16, 1, 62]` and apply `MulipleResidualGCN` (same as Saber)
- Flatten → FC(→64) → ReLU → FC(64→64) → ReLU

**Key design:**  
Encodes temporal dynamics first (GRU per electrode), then uses the resulting per-electrode hidden states as node features for spatial graph convolution. Temporal and spatial processing are decoupled.

---

## Temporal MLP (saber_t.py — `TemporalMLPExtractor`)

Same multi-window input as above but without graph structure.

**Architecture:**
- Flatten to `[B, T, 62*5=310]`
- GRU: `input_size=310, hidden_size=128`
- Final hidden state → FC(128→64) → ReLU → FC(64→64) → ReLU

---

## TAHAG sharedNet (TAHAG_Independent.py — `sharedNet`)

Input `[B, 310]`, reshaped to `[B, 5, 62]`.

**Architecture:**
- BatchNorm on 5 bands
- 3× `unit_gcn` layers: 5→32→64→128
- Global mean pool over electrodes → `[B, 128]`

Output dim is **128**, not 64. Also returns intermediate feature maps from layers 1 and 2 (used for MMD domain alignment loss).

**`unit_gcn` internals:**  
Each unit has a fixed adjacency (from `get_adj_from_standard`) plus a learnable offset computed as `A_adaptive = PA + α·tanh(conv_a^T · conv_b / in_feats)` — similar to Saber's per-sample mechanism but the offset is global (not per-sample). Also includes an SE-style channel attention (FC bottleneck on per-sample feature means) and residual connections.

---

## EEGNet (EEGNet.py — `EEGNet`)

Not a DE feature extractor — operates on **raw time-series** input `[B, 62, 128]` (channels × time samples). Included for completeness.

**Architecture:**
- Temporal Conv2d: 1→F1 channels, kernel (1,64)
- Depth-wise spatial Conv2d: F1→F1×D channels, kernel (62,1) — one filter per input channel
- Average pool → Dropout → Separable Conv → Average pool → Dropout
- FC → num_classes

EEGNet is designed for time-domain input, not frequency-band DE features. Not directly usable as a drop-in replacement in this project without a different data pipeline.
